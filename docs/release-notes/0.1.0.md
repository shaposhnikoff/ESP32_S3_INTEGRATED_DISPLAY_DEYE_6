# Deye HMI 0.1.0

First monitoring build, flashed and partially validated on the 5B board.
Physical interaction, long-duration stability and OTA checks remain pending.

* Ten-screen LVGL 9 UI for the Waveshare ESP32-S3-Touch-LCD-5B (1024x600).
* Read-only telemetry from the Deye Prometheus exporter (`GET /metrics`),
  with stale/offline detection and backoff.
* Bounded on-device history and charts (24 h @1 min, 7 d @15 min).
* Control safety layer implemented and tested; **all inverter writes
  disabled** (no write API, no verified parameters).
* Wi-Fi provisioning on screen, NVS settings, optional PIN, OTA with
  rollback, diagnostics.
* Ignored local network profile for automatic provisioning and connection.
* Real device screenshots over the LAN, with Overview and other captures
  published in the README.
* Glanceable Overview with distinct on-battery, on-grid, low-battery, fault,
  and no-data states; live captures of both power-source states are included.
* Battery runtime and time-to-full estimates use the configured 15 kWh nominal
  capacity and 20% discharge cutoff. These values are display-only and do not
  change inverter settings.
* Bottom navigation with six primary screens and a More menu for the remaining
  screens. Today's energy totals are available on Charts.
