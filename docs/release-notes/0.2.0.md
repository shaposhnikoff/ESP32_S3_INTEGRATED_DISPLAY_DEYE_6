# Deye HMI 0.2.0

The firmware now targets the Waveshare ESP32-S3-Touch-LCD-7B (7-inch,
1024x600). The live Overview was flashed and captured on a physical 7B board.

* New Overview with a 24-hour Europe/Kyiv outage dial, status headline,
  inverter card and six detail tiles.
* Battery runtime estimate uses the configured 15 kWh capacity, 20% reserve
  and a recent five-minute average of measured house load.
* A background HTTPS reader downloads the public Kyiv-region JSON every 10
  minutes, validates freshness, and displays confirmed outages for group 4.1.
* Hourly ticks, a white current-time hand and a 24-hour legend make the dial
  readable as a clock.
* TLS buffers and the outage task stack use PSRAM. Only Overview is constructed
  at runtime; after a live fetch and screenshot, minimum free internal RAM was
  22.7 KB, up from 251 bytes with all screens constructed.
* Updated 7B RGB panel timing, touch reset and backlight driver.
* The bottom navigation and other pages are hidden in the single-screen build.
* The public release workflow builds from a clean checkout without a local
  network profile. Local packaging refuses to run while one exists.

Inverter writes remain disabled.
