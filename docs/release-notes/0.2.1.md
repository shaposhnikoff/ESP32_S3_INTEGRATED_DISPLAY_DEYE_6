# Deye HMI 0.2.1

The single-screen Overview now keeps the 7B backlight on continuously,
including when NVS contains a timeout saved by earlier firmware. New
installations default to a zero-second timeout. Telemetry and outage schedule
behavior are unchanged.

The public firmware contains no local Wi-Fi profile. The connected board was
flashed with a private local build; its network configuration is not included
in this release.
